# Hochzeitseinladung Claudia & Florian

- Deutsch: https://florianaubruner-coder.github.io/
- Slowakisch: https://florianaubruner-coder.github.io/sk/

Ein rosé Umschlag mit geprägten Blumen und Wachssiegel öffnet sich beim Antippen: Gold schimmert über die Blumen, die Lasche hebt sich, warmes Licht, dann erscheint die Einladung mit Musik. Danach folgen Familienfoto, Countdown, Ablauf mit mitlaufendem Siegel, Ort mit Fotos, Momente, „Unser Lied“ und Zusage per WhatsApp.

## Persönliche Links

- Deutsch: `https://florianaubruner-coder.github.io/?an=Familie%20Huber` → „Für Familie Huber“ auf dem Umschlag, Name im Zusage-Formular vorausgefüllt.
- Slowakisch: `https://florianaubruner-coder.github.io/sk/?pre=rodinu%20Novákovcov` → „Pre rodinu Novákovcov“ (Name im 4. Fall).

Leerzeichen als `%20` schreiben.

## Anpassen

- **WhatsApp-Nummer, Zusage-Frist, Spotify-Link:** ganz unten in `index.html` bzw. `sk/index.html` im Block `CONFIG` (`whatsapp`, `rsvpBy`, `spotify`).
- **Texte:** Deutsch in `index.html`, Slowakisch in `sk/index.html`. Änderungen am Inhalt in beiden Dateien machen.
- **Musik:** `musik.mp3`, eure eigene Aufnahme (Brummen, Rumpeln und Rauschen reduziert, Lautstärke angeglichen, Standortdaten entfernt).
- **Vorschaubilder für WhatsApp:** `og.jpg` (Deutsch), `og-sk.jpg` (Slowakisch).
- **Kalender:** `hochzeit.ics`, `svadba.ics`.
- **Fotos:** `img/` (Ort: `img/ort-*.jpg`).
